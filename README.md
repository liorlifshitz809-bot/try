# Run locally (macOS)

This repo is a pnpm workspace with:
- API server: `artifacts/api-server`
- Web app: `artifacts/piano-conservatory`

## 1) Install deps

```bash
corepack enable
pnpm install
```

## 2) Start Postgres

Option A (Docker):

```bash
docker compose up -d
```

Then use:

```bash
DATABASE_URL=postgres://postgres:postgres@localhost:5432/piano_conservatory
```

Option B (Local Postgres):
- Ensure Postgres is running locally
- Create a DB named `piano_conservatory`
- Set `DATABASE_URL` accordingly

## 3) Create tables

The DB schema is defined in `lib/db/src/schema/*`. Push it to your database:

```bash
DATABASE_URL=postgres://postgres:postgres@localhost:5432/piano_conservatory \
  pnpm --filter @workspace/db push
```

## 4) Run the API

```bash
PORT=8080 \
DATABASE_URL=postgres://postgres:postgres@localhost:5432/piano_conservatory \
pnpm --filter @workspace/api-server dev
```

## 5) Run the web app

In a second terminal:

```bash
PORT=5173 \
BASE_PATH=/ \
API_SERVER_PORT=8080 \
pnpm --filter @workspace/piano-conservatory dev
```

Open `http://localhost:5173`.

## Access from other devices / internet (HTTPS)

### Local network (LAN)
- Find your machine IP (example `192.168.x.x`) and open:
  - `http://192.168.x.x:5173`

### Secure tunnel (ngrok HTTPS)
WebRTC requires a secure context when accessed from the public internet. Use a tunnel:

```bash
pnpm tunnel
```

Then open the `https://...ngrok-free.app` URL ngrok prints.

## Deploy on Render

This repo includes a `render.yaml` Blueprint to deploy the API and web app as a single Node web service.

### 1) Create Postgres on Render

- Create a Render Postgres database
- Copy its `Internal Database URL`
- Use that value for `DATABASE_URL` on the web service

### 2) Create service from Blueprint

- Push this repo to GitHub/GitLab
- In Render, choose **New +** -> **Blueprint**
- Select this repo and apply the `render.yaml` settings

Render will run:

- Build: `corepack enable && pnpm install --frozen-lockfile && pnpm --filter @workspace/piano-conservatory build && pnpm --filter @workspace/api-server build`
- Start: `pnpm --filter @workspace/api-server start`

The API health check is: `/api/healthz`

### 3) Set required environment variables

- `DATABASE_URL` (from your Render Postgres)
- `JWT_SECRET` (auto-generated by the Blueprint; replace if you want your own)

### 4) Apply DB schema once

After first deploy, open a Render Shell for the service and run:

```bash
pnpm --filter @workspace/db push
```

After that, your app should be available at your Render service URL.
